# 个人与企业网站建设技能

作者：Kevin Shu · GitHub：kevinshu09

面向中文用户的 AI 建站工作流指南。支持从需求和参考风格出发，完成页面、表单、手机/平板/电脑适配以及可选的网站上线。

## 它是什么

这是提供给支持技能文件的 AI 助手的操作指南，不是网站模板、可执行应用或一键建站服务。实际效果取决于所用 AI、工具、账号权限与需求复杂度。

包内不包含任何托管账号、API 密钥、私人表格连接或原作者的网站源码。使用者需要自己的相关账号。第三方服务的价格、额度和可用性以其当前规则为准。

## 安装与使用

将整个 `website-launch` 文件夹放入你的 Codex 技能目录，通常为 `~/.codex/skills/`。如果设置了 CODEX_HOME，则使用它下面的 `skills/`。目录结构应为 `skills/website-launch/SKILL.md`，不要多嵌套一层同名文件夹。让当前客户端重新加载技能；仍未出现时，重启客户端或开启新任务。

开始时可以输入：

> 使用 $website-launch 为我的咨询业务建一个中文网站。我希望访客了解服务并提交咨询；先做本地预览，确认后再上线。

也可以提供现有网站、需求文档、截图、设计参考、图片、品牌资料或预算。不要在对话中粘贴密码和密钥。

其他 AI 工具是否支持这种技能结构需要各自确认；复制提示文本不等于获得文件访问、浏览器或部署能力。

## 内置需求发现 ABCD

新建完整网站时，先帮助你找到需求和答案，再开始制作：

| 阶段 | 如何进行 | 产出 |
|---|---|---|
| A 需求发现 | 分三轮了解事实、动机与约束，再测试关键假设；已有答案不重复问 | 事实表与未知清单 |
| B 方案展开 | 比较不同路径与暂不建站，对最高风险选择追踪 L0–L5 后果 | 方案比较、新选项与风险链 |
| C 筛选决定 | 解释具体障碍、根因、替代路径及保留理由 | 经你确认的建站计划 |
| D 私人存档 | 保存决定及原因，后续更新实际结果 | 项目私人记录，不随网站公开 |

然后进入下面的建站执行阶段。执行中出现重要新事实，会重新检查受影响决定。

**你可以控制探索深度。**要求缩短或停止提问时，AI 应记录未知项后继续可执行的工作；必要的账号授权仍由你完成。改标题、替换图片、增加已明确的下拉选项等小修改，不会重新要求三轮问答。

本包已包含建站版 ABCD，不需要另装 Buddha。它保留需求发现与后果推演的方法，同时避免为小改动、每行代码机械产生多套方案。

## 执行流程与检查点

| 阶段 | AI 要做什么 | 产出与通过条件 |
|---|---|---|
| 1 需求 | 确认受众、目标、品牌、语言、功能、现有项目与账号条件 | 简明需求记录；关键缺口明确 |
| 2 内容 | 整理页面结构、服务说明、可信依据、行动按钮 | 不虚构资质、合作、案例和效果 |
| 3 视觉 | 分析参考的字体、颜色、留白和图片构图 | 适合本项目的风格，不照搬他人身份 |
| 4 实现 | 搭建或修改代码，提供可用预览并迭代 | 页面能打开，主要链接和交互可用 |
| 5 表单（可选） | 确定字段与保存位置，按需接通后端 | 必填校验；失败保留答案；保存确认后才报成功 |
| 6 多设备验证 | 检查手机、平板、电脑及键盘操作 | 无明显溢出、遮挡或无法操作；未验证部分明确 |
| 7 上线（可选） | 在明确授权下部署、配置域名和 HTTPS | 生产链接可访问，域名和证书分别核实 |
| 8 交接 | 交付链接、代码位置、询盘位置和验证记录 | 明确已完成、未完成、谁负责后续维护 |

表单可用 Google Sheets、现有 CRM、数据库或其他服务；不强制 Formspree，也不固定 Vercel。Google Sheets 分支通常在最后一步提交一次完整记录，并按请求 ID 防止重试重复。

阶段可以按项目调整。简单文案修改无需重做整套流程；原有工作和用户明确选择优先。未要求上线时，不擅自公开网站。
